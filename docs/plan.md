## 计划概述
校园二手交易平台，按「基础 → 交易 → 秩序与增强」三段推进，共 13 个子功能，预估 6~8 周。沿用现有框架技术栈：前端 Vue3 + Element Plus，后端 Spring Boot + MySQL + Flyway，Web 单页应用（可响应式适配手机浏览器）。

|---|---|---|---|---|

## 里程碑
- **里程碑 1 · 基础可用**（第 1-5 项）：骨架 + 账号体系 + 商品发布浏览闭环。完成后用户已能注册登录、发布商品、浏览搜索、收藏。
- **里程碑 2 · 交易闭环**（第 6-9 项）：私信 + 求购 + 钱包 + 担保交易。完成后一笔带资金托管的二手交易可全流程走通，这是系统核心。
- **里程碑 3 · 秩序与增强**（第 10-13 项）：评价信誉、举报处理、管理员后台、站内通知。完成后系统秩序可控、可统计，达到毕设答辩标准。

## 风险与对策
1. **WebSocket 私信（第 6 项）**：已确认采用 WebSocket 方案（2026-10-22），不默认降级；若因环境原因实在无法实现，轮询仅作极端兜底。
2. **担保交易状态机（第 9 项）**：订单状态流转需严谨设计，接口做幂等处理，防止重复付款/重复确认收货等并发问题。
3. **钱包余额一致性（第 8、9 项）**：付款、结算、提现涉及余额变动，一律走数据库事务，避免金额对不上。
4. **图片上传存储（第 3 项）**：商品多图存本地磁盘目录即可，不接对象存储。

## 卡点确认（2026-10-22，用户已确认）
- **卡点 2（WebSocket）**：私信确定使用 WebSocket 实现，不做轮询降级。
- **卡点 3（交易/钱包并发）**：防重复点击是硬要求——付款、确认收货等操作必须幂等（条件更新 + 钱包行锁）。
- **卡点 4（双角色体系）**：认可「用户端 + 管理端」方案，登录后按角色路由分流。
- **卡点 5（图片存储路径）**：确定为 `backend/uploads/goods/` 目录 + 日期子目录；数据库只存相对 URL（如 `/uploads/goods/2026-10-22/xxx.jpg`），不存绝对路径；后端静态资源映射 `/uploads/**`；限制 jpg/png/webp、单张 ≤5MB、最多 9 张。
- **卡点 6（前端页面量）**：认可「先跑通主干、再补细节」的推进节奏。

## 开发注意事项（2026-10-22 补充，开发前先定规则）
1. **订单超时/取消规则（第 9 项）**：需求未定义，建议定为「下单 24 小时未付款自动取消；已付款后买家 7 天不确认收货可向管理员申诉或自动完成」。
2. **下架/封禁与进行中交易的联动（第 11 项）**：商品下架不影响已下单未完成订单；封禁只限制交易/发言，不影响已完成订单结算，钱包提现仍可申请。
3. **私信消息必须落库（第 6 项）**：WebSocket 消息需存数据库（举报私信要有记录可查），不能只推不存；被禁言用户在 WebSocket 发消息时实时拦截，不能只拦 HTTP 接口。
4. **接口级角色校验（第 2、12 项）**：现有安全配置只拦「未登录」，需为业务接口加角色鉴权，防普通用户直接调管理员接口（改 URL 越权）。
5. **提现冻结余额（第 8 项）**：提交提现时冻结对应金额，审核拒绝才解冻，防止审核期间余额被花成负数。
6. **演示数据脚本（答辩准备）**：功能完成后准备演示数据——几个分类、几十个商品、测试账号（管理员+买卖双方）、已完成订单与评价，答辩一打开就是「活跃的二手市场」。
7. **前端页面清单**：用户端（登录/注册、商品列表、商品详情、发布商品、求购列表/发布、订单列表/详情、下单支付、钱包/充值/提现、私信会话/聊天、个人中心/收藏/评价、卖家主页）+ 管理端（审核、用户、举报、提现、分类、统计），开发时逐项对照不遗漏。

## 版本控制策略（2026-10-22）
- 框架已有 AI 隔离机制：AI 业务代码写入 `backend/src/main/java/com/thesisforge/ai/`、`frontend/src/views/ai-biz/`、`frontend/src/api/ai-biz.js`，均被 .gitignore 排除，**不进主仓库 git、不上传 GitHub**；框架文件的最小改动留 git 可回滚。
- 业务代码不进 git 的代价是无版本历史、无法回滚，**计划对隔离目录单独 git init 建本地独立仓库**（与主仓库零干扰），每完成一个子功能提交一次，保留完整开发轨迹（待确认后执行）。
- 每完成一个子功能做一次干净提交（一项一提交），节点记录只本地不 push。
